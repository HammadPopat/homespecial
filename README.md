# Murtuza’s Table • Fresh Homemade Food Delivery

An artisanal, warm minimalist e-commerce platform for ordering fresh home-cooked meals, slow-dum biryanis, and artisan bakery treats delivered directly to doorsteps.

## ✨ Features
- **Warm Minimalist & Tactile Design**: Handcrafted editorial food aesthetics, warm oat & terracotta color palette, delicate typography (Playfair Display & Plus Jakarta Sans).
- **Interactive Menu & Live Filtering**: Filter by category (Ammi's Curries & Biryani, Comfort Daal & Sabzi, Daily Thali / Tiffin, Parathas & Roti, Artisan Bakes & Mithai, Shaam Ki Chai Snacks) and dietary preference (Pure Veg, Non-Veg, Sweet Tooth).
- **Dish Customization Modal**: Choose serving portions (Single, Duo, Family Handi), spice levels (Mild, Medium, Spicy), and add chef notes.
- **Slide-Over Tiffin Basket (Cart Drawer)**: Real-time price calculation, dynamic free delivery progress bar, and promo code support (`HOMELOVE`, `FIRSTBITE`).
- **Seamless WhatsApp & Web Ordering**: Formats a complete structured receipt and forwards it directly to WhatsApp for instant customer confirmation.
- **Weekly Tiffin Subscriptions**: Dedicated trial booking and inquiry system for daily office lunch thalis.
- **100% Responsive**: Tailored for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- HTML5 Semantic Markup
- Vanilla CSS3 (Custom Design System, Flexbox, Grid, Glassmorphism)
- Pure JavaScript (ES6+, LocalStorage state persistence)
- Font Awesome Icons & Google Fonts
